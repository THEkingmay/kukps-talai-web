# 01: Setup Infrastructure (Shadcn, Font, Dark Mode)

**What to build:** The foundational UI layer using Vercel's style. This involves importing the Prompt font for a modern look, setting up Shadcn UI for Tailwind v4, and providing a ThemeProvider that allows toggling between light and dark modes across the application.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Prompt font is imported and applied globally.
- [ ] Shadcn UI components (button, dialog, sheet, input, label, separator, badge, avatar, scroll-area, tooltip, dropdown-menu, skeleton, card, navigation-menu) are correctly initialized.
- [ ] A ThemeProvider is implemented, and the user can switch between Light and Dark mode using CSS variables styled like Vercel.
